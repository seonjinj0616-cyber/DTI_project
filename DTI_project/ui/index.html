① 스크리닝 Top100

MoLFormer + Ki/Kd 분류 모델로 인간 단백질 전체에서 고른 고유 UniProt Top100

Ki 확률 · Kd 확률은 입력 화합물이 이 단백질에 강하게 결합할 확률을 모델이 예측한 값(0~1)입니다. 학습 때 결합 상수가 pKi(또는 pKd) ≥ 7, 즉 Ki(또는 Kd) ≤ 100 nM 인 화합물-단백질 쌍을 "결합함"으로 두고 분류했습니다.

두 값은 같은 모델의 두 출력(멀티태스크)이며, 서로 다른 실험 데이터(ChEMBL·BindingDB 의 Ki, Kd 측정값)로 학습했습니다.

선별 방법: 인간 단백질 약 11.3만 개(정상 서열 + 변이 서열) 중 Ki 확률 ≥ 0.5 인 것을 Ki 확률 순으로 최대 1000개 모으고, 그 안에서 Kd 확률 ≥ 0.5 인 것을 Kd 확률 순으로 훑으며 같은 UniProt 은 하나만 남겨 100개를 고릅니다. 확률은 순위를 매기기 위한 모델 점수이므로 실제 결합 여부는 실험으로 확인해야 합니다.

② 재랭킹과 결합 부위

IC50 회귀로 Top20 재랭킹, attention peak 로 최종 표적 선택. 행을 누르면 attention 프로필을 봅니다.

③ 적응증 후보

Open Targets 질병 근거 + PrimeKG 매핑 + TxGNN 점수

최종 표적 단백질과 연결된 질병을 두 가지 독립된 근거로 평가합니다.

  • Open Targets 근거 점수 (OT): "이 표적 단백질이 이 질병과 관련 있다"는 근거의 세기(0~1)입니다. 유전학, 문헌, 동물 모델 등 근거 중 가장 높은 점수이며, 0.4 이상인 것만 후보로 남깁니다. 약물이 아니라 표적 기준의 점수입니다.
  • TxGNN 상위 %: 의학 지식 그래프(PrimeKG)로 학습한 TxGNN 이 "입력 약물이 이 질병의 치료제일 가능성"을 전체 질병 약 8천 개 중 몇 등으로 예측했는지를 백분율로 나타낸 값입니다. 작을수록 상위(예: 2.4 = 상위 2.4%)입니다.

상위 20개 질병 후보

표의 순위(TxGNN 순위가 높은 순)대로 20개만 보여줍니다. 두 막대 모두 길수록 근거가 강합니다. 두 막대가 모두 긴 질병이 먼저 살펴볼 후보입니다.

표의 열 설명
  • 표적: 이 질병과 연결된 최종 표적 유전자. 여러 개면 여러 표적이 같은 질병을 가리킨다는 뜻입니다.
  • OT 최대 / 평균: 표적-질병 근거 점수의 최댓값과 평균(표적이 여러 개일 때).
  • TxGNN 순위 / 상위%: 입력 약물에 대한 TxGNN 적응증 예측 순위. 비어 있으면 질병을 PrimeKG 에 매핑하지 못한 경우입니다.
  • 점수 출처: query 는 입력 약물 자체의 점수, proxy 는 입력 약물이 PrimeKG 에 없어 같은 표적을 가진 다른 약물(괄호 안)로 대신 계산한 점수입니다.
  • KG 기존: yes 면 이 약물-질병 적응증이 이미 PrimeKG 에 알려져 있다는 뜻(새 발견이 아님)입니다.
  • 근거 유형: Open Targets 근거 종류. 예: literature(문헌), genetic_association(유전 연관), animal_model(동물 모델), known_drug(기존 약물).
  • 관련 경로: 표적이 참여하는 Reactome 경로 중 이 질병과 연결된 것.

④ 안전성 · 경로

참고용 정보입니다. 표적별 안전성 근거와 Reactome 경로, 입력 약물의 알려진 부작용

＋ 새 분석

약물 이름과 DrugBank ID 는 비워 두어도 SMILES 로 PubChem 을 조회해 PrimeKG 약물을 자동으로 찾습니다. 자동으로 못 찾았다는 안내가 나오면 그때 약물 이름(PrimeKG 이름과 같게, 영문)이나 DrugBank ID 를 넣어 다시 실행하세요.

입력 약물이 PrimeKG 지식 그래프에 없으면(신규 화합물 등) TxGNN 점수를 낼 수 없습니다. 체크하면 이때만 최종 표적을 표적으로 하는 기존 약물을 최대 20개 골라 대신 점수를 계산하고, 결과에 proxy 로 표시합니다. 입력 화합물 자체의 점수가 아니라 참고용입니다. 적응증 화면에 "TxGNN 점수 없음"이 나올 때 체크하고 다시 실행하세요.

결과는 항상 results/ 폴더에 CSV 로 저장됩니다. 체크하면 같은 결과를 data/open_target_dataDB/cdss_integrated.db 의 analysis_history, step3_indication_results 테이블에도 저장합니다. 다른 프로그램이 DB 에서 결과를 읽어야 할 때만 체크하면 되고, 화면으로 보는 데는 필요 없습니다.
